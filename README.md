# Snoopy's Home

A textured personal archive for birthdays, concerts, quick todos, repeat lists, notes, focused flights, listening history, and specific trackers. The same data is available offline and syncs through Convex after signing in.

## Install on Windows

1. Open the deployed site in Microsoft Edge or Google Chrome.
2. Open the profile menu in the top-right corner.
3. Select **install pc app**.

The installed PWA opens in its own window, keeps an offline copy, and uses the same account and archive as the iPhone version.

## Development

```powershell
npm install
npx convex dev
npm run dev
```
